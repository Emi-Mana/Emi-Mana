# Emi & Manato 減量チャレンジ

2人の体重記録サイト（GitHub Pages）。記録はLINE公式アカウントに体重の数字を送るだけ。

- `index.html` … サイト本体。`API_URL` に Apps Script のURL
- `chara.js` … キャラクターの絵（服・髪型・帽子・持ち物・背景のパーツ）
- `game.js` … 物語・アイテム・レベルのデータ。文やアイテムを変えるときはここ
- `apps-script.gs` … スプレッドシートの Apps Script に貼るコード（LINEの記録、食事アドバイス、アイテムの保存）
- `icon.jpg` … アイコン
